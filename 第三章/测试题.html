一、单选题 每题只有一个正确答案

1.Transformer LLM 生成文本的方式是？
  • A一次性并行生成所有输出文本
  • B一次生成一个词元，循环往复
  • C先生成整句再逐词修正
  • D按段落分块生成
答案：B Transformer LLM 每次只生成一个词元；生成的词元被追加到提示词末尾，更新后的提示词再次输入模型进行下一次前向传播，如此循环（见图 3-2、图 3-3）。
2.模型生成第一个词元后，为了生成第二个词元，输入如何变化？
  • A只把新词元单独送入模型
  • B把输出词元追加到输入提示词末尾，再整体进行前向传播
  • C丢弃原提示词，只用新词元
  • D随机挑选一段上下文重新输入
答案：B 在生成当前词元后，输出词元会追加到输入提示词的末尾，从而调整下一次生成的输入提示词（见图 3-3），这就是自回归的逐词元生成过程。
3.下列哪项不属于Transformer LLM 的三个主要组件？
  • A分词器
  • B一系列堆叠的 Transformer 块
  • C语言建模头（LM head）
  • D独立的检索数据库
答案：D Transformer LLM 的三个主要组件是：分词器（含词元词表）、一系列 Transformer 块、语言建模头（见图 3-4）。检索数据库不属于其组成部分。
4.语言建模头（lm_head）的作用是？
  • A把文本分解成词元
  • B把 Transformer 块的输出向量转换为词表中每个词元的概率分数
  • C缓存之前的计算结果
  • D为词元添加位置信息
答案：B 语言建模头是一个简单的神经网络层，它接收最后一个 Transformer 块输出的向量，输出大小等于词表大小的向量，即每个词元的概率分数，用于选择下一个输出词元。
5.每次都选择概率分数最高的词元的解码策略是？
  • A随机采样
  • B束搜索
  • C贪心解码
  • D自监督解码
答案：C 贪心解码就是每次都选择概率分数最高的词元；在 LLM 中把温度（temperature）参数设为零时发生的就是贪心解码。实践中按概率采样往往能产生更好的输出。
6.lm_head_output 的形状为 [1, 5, 32064]，访问最后一个词元概率分数的正确索引是？
  • Alm_head_output[0, 0]
  • Blm_head_output[0, -1]
  • Clm_head_output[-1, 0]
  • Dlm_head_output[1, 5]
答案：B 索引 0 用于批次维度（一批中的第一个输入），索引 -1 用于获取序列中最后一个词元的位置，得到全部 32064 个词元的概率分数列表。
7.Transformer 模型一次可以处理的词元数量限制被称为？
  • A批次大小
  • B上下文长度
  • C词表大小
  • D嵌入维度
答案：B 当前 Transformer 模型对一次可以处理的词元数量有限制，称为模型的上下文长度。4K 上下文长度的模型只能处理 4000 个词元，也就是只有 4000 条计算流。
8.文本生成时只使用最后一条计算流的输出预测下一个词元，为什么仍需要所有计算流？
  • A为了让显存占用最大化
  • B因为每个 Transformer 块的注意力机制需要使用前序流的早期输出
  • C因为所有流的最终输出都要拼接后送入 lm_head
  • D其实不需要，只计算最后一条流即可
答案：B 虽然只用最后一条流的最终输出向量预测下一个词元，但之前各流在每个 Transformer 块注意力机制中的早期输出是最终的流所必需的，它们为当前词元提供上下文信息。
9.KV 缓存缓存的是哪些向量？
  • A词元嵌入向量
  • B注意力机制中的键（Key）和值（Value）向量
  • C语言建模头的输出分数
  • D位置嵌入向量
答案：B KV（键-值）缓存把之前词元在注意力机制中的键和值等特定向量缓存下来，生成新词元时无需重复计算之前的流，只需计算最后一条流，从而显著加快生成（见图 3-10）。
10.在 Hugging Face Transformers 中，禁用 KV 缓存的参数设置是？
  • Acache=False
  • Buse_cache=False
  • Ckv_cache=off
  • Ddisable_cache=True
答案：B 缓存默认是启用的，将 use_cache 设置为 False 可以禁用。书中示例里生成 100 个词元，启用缓存约 4.5 秒，禁用后约 21.8 秒，差异非常显著。
11.Transformer 块由哪两个首尾相接的组件构成？
  • A分词器和语言建模头
  • B自注意力层和前馈神经网络层
  • C卷积层和池化层
  • D编码器和解码器
答案：B Transformer 块由自注意力层（主要负责整合来自其他输入词元和位置的相关信息）和前馈神经网络层（包含模型的主要处理能力）首尾相接构成（见图 3-12）。
12.输入"The Shawshank"后模型能续写出"Redemption"，这类事实性知识主要存储在哪？
  • A分词器的词表中
  • B注意力层的查询矩阵中
  • C前馈神经网络层（分布在所有模型层中）
  • DKV 缓存中
答案：C 前馈神经网络层（分布在所有模型层中）承担了模型大部分的记忆和插值工作：模型在大规模文本上训练后，把完成任务所需的信息存储在 FFN 中，并能利用相同机制在数据点之间插值实现泛化（见图 3-13）。
13.注意力机制第一步"相关性评分"是如何计算的？
  • A将当前位置的查询向量与键矩阵相乘，再通过 softmax 归一化
  • B将值矩阵与键矩阵逐元素相加
  • C将查询矩阵与值矩阵相乘后取平均
  • D用余弦相似度比较词元嵌入
答案：A 相关性评分通过将当前位置的查询向量与键矩阵相乘实现，产生衡量前序每个词元相关性的分数，随后用 softmax 归一化使分数之和为 1（见图 3-20）。
14.多查询注意力（MQA）通过什么方式实现优化？
  • A在所有注意力头之间共享键矩阵和值矩阵，每个头只保留独特的查询矩阵
  • B让每个头使用多组键值矩阵
  • C删除所有注意力头
  • D把注意力计算移到 CPU 上
答案：A 多头注意力中每个头有独立的查询、键、值矩阵；多查询注意力让所有头共享键矩阵和值矩阵，只保留各自独特的查询矩阵，通过减小矩阵规模提升推理可扩展性（见图 3-27）。
15.旋转位置嵌入（RoPE）在前向传播的哪个环节加入位置信息？
  • A前向传播开始时的嵌入阶段
  • B语言建模头的概率计算中
  • C注意力步骤中，在查询与键相乘做相关性评分之前混入查询矩阵和键矩阵
  • D输出词元解码时
答案：C 与在前向传播开始时添加的静态绝对嵌入不同，RoPE 在注意力步骤中把位置信息特意混合到查询矩阵和键矩阵中，发生在查询向量与键矩阵相乘进行相关性评分之前（见图 3-32、图 3-33）。

二、多选题 每题有两个及以上正确答案

1.关于 Transformer LLM 的自回归逐词元生成，下列说法正确的有？
  • A模型一次前向传播只用于生成一个词元
  • B生成的词元会被追加到提示词末尾
  • C更新后的提示词会再次输入模型进行下一次前向传播
  • D所有输出词元在第一次前向传播中同时产生
答案：ABC 文本生成是循环执行"前向传播 → 选出词元 → 追加到提示词 → 再次前向传播"的过程；D 错误，词元是逐个生成的，并非一次同时产生。
2.打印 Phi-3 模型结构（print(model)）后，可以观察到哪些信息？
  • A堆叠了 32 个 Phi3DecoderLayer 类型的块
  • B嵌入矩阵 embed_tokens 有 32064 个词元
  • C每个词元的向量大小为 3072
  • Dlm_head 输出向量大小为 3072
答案：ABC Phi3Model 内 embed_tokens 的维度是 32064×3072（32064 个词元，每个 3072 维），包含 32 个 Phi3DecoderLayer；lm_head 接收 3072 维向量、输出等于词元数量的 32064 维向量，D 说反了。
3.关于注意力机制的两个主要步骤，下列说法正确的有？
  • A第一步是对当前处理的词元与之前输入词元进行相关性评分
  • B第二步是利用这些分数将不同位置的信息组合成单一输出向量
  • C评分通过查询向量与键矩阵的交互完成
  • D信息组合时把所有值向量直接相加，与相关性分数无关
答案：ABC 注意力分两步：先由查询向量和键矩阵相乘（softmax 归一化）得到相关性分数，再用每个词元的值向量乘以该词元的分数后相加，得到输出（见图 3-21）；D 错误，组合必须以分数加权。
4.关于并行词元处理与计算流，下列说法正确的有？
  • A每个输入词元都流经自己的计算流（处理路径）
  • B计算流的数量就是模型的上下文长度
  • C每条流以一个输入向量开始，输出一个大小相同的结果向量
  • D输入向量与输出向量的大小可以任意不同
答案：ABC 每个词元流经独立计算流，流数量即上下文长度；每条流从输入向量（嵌入+位置信息）开始，产出大小相同的输出向量，该大小通常称为模型维度（见图 3-9），D 错误。
5.关于分组查询注意力（GQA），下列说法正确的有？
  • A它建立在多查询注意力（MQA）的基础之上
  • B每个分组的注意力头共享各自的键矩阵和值矩阵
  • CLlama 2 和 Llama 3 等模型使用了 GQA
  • DGQA 中键、值矩阵的数量与注意力头数量相同
答案：ABC GQA 在 MQA 基础上，允许使用多于一个但少于注意力头数量的键、值矩阵，分组共享；它在牺牲一些 MQA 效率的同时换取质量的大幅提升，被 Llama 2/3 采用；D 错误，若数量与头数相同就退回多头注意力了。
6.相比原始 Transformer 论文，2024 年的 Transformer 块（如 Llama 3）有哪些改进？
  • A归一化移到自注意力层和前馈神经网络层之前（预归一化）
  • B使用比 LayerNorm 更简单高效的 RMSNorm
  • C激活函数采用 SwiGLU 等新变体替代 ReLU
  • D完全移除了注意力机制
答案：ABC 新版 Transformer 块保留残差连接与层归一化，但归一化前置（据称可减少训练时间）、用 RMSNorm 替代 LayerNorm、用 SwiGLU 等替代 ReLU，并配合 GQA 和 RoPE 优化注意力；注意力机制仍是核心组件，D 错误。

三、判断题 判断下列说法是否正确

1.Transformer LLM 会对整个输出文本一次性完成生成。
  • √正确
  • ×错误
答案：× 模型一次只生成一个词元，生成后追加到提示词再进行下一次前向传播，循环往复直到完成。
2.贪心解码总是选择概率分数最高的词元作为输出。
  • √正确
  • ×错误
答案：√ 贪心解码每次都选概率分数最高的词元，等价于温度参数设为零；实践中引入随机性的采样策略往往效果更好。
3.一个 4K 上下文长度的模型一次最多可以处理 5000 个词元。
  • √正确
  • ×错误
答案：× 4K 上下文长度意味着只能处理 4000 个词元，即只有 4000 条计算流，5000 超出了限制。
4.解码器 Transformer 块的注意力可以关注序列中后续位置的词元。
  • √正确
  • ×错误
答案：× 构成大多数文本生成模型的解码器 Transformer 块具有自回归特性，只能关注前序词元；BERT 这类双向模型才可以关注两个方向。
5.GPT-3 在所有 Transformer 块中都使用稀疏注意力。
  • √正确
  • ×错误
答案：× 如果模型只能看到少量前序词元，生成质量会大幅下降，因此 GPT-3 在全注意力和稀疏注意力的 Transformer 块之间交替使用，而非全部使用稀疏注意力。
6.Flash Attention 通过优化 GPU 共享内存（SRAM）和高带宽内存（HBM）之间的数据加载和迁移来加速注意力计算。
  • √正确
  • ×错误
答案：√ Flash Attention 是广受欢迎的精确注意力加速方法，从 IO 角度优化 SRAM 与 HBM 之间的数据加载和迁移，可显著提升 GPU 上训练和推理速度。
7.RMSNorm 比原始 Transformer 中使用的 LayerNorm 更简单、更高效。
  • √正确
  • ×错误
答案：√ 现代模型（如 Llama 系列）用 RMSNorm 替代 LayerNorm，它更简单、更高效，这也是 Transformer 块的重要改进之一。
8.旋转位置嵌入（RoPE）只能编码词元的绝对位置信息。
  • √正确
  • ×错误
答案：× RoPE 是一种以捕获绝对和相对词元位置信息的方式来编码位置的方法，其思想基于嵌入空间中旋转的向量。
9.打包（packing）是指将多个短训练文档高效组织到同一个训练上下文中。
  • √正确
  • ×错误
答案：√ 训练集中很多文档长度远小于上下文长度，为短句分配整个 4K 上下文很低效，因此训练时会把多个文档一同打包进每个批次的上下文，同时尽量减少末尾填充（见图 3-31）。
10.在 Hugging Face Transformers 中，KV 缓存默认是关闭的，需要手动开启。
  • √正确
  • ×错误
答案：× 缓存默认是启用的；如需禁用，才将 use_cache 设置为 False。禁用后生成同样 100 个词元的时间从约 4.5 秒增加到约 21.8 秒。

四、填空题 点击「显示答案」查看空内内容

1.使用早期预测来进行后续预测的模型（例如用生成的第一个词元来生成第二个词元）被称为自回归模型。
答案：自回归（autoregressive） 这是机器学习中描述此类模型的专门术语，LLM 逐词元生成文本的底层过程正是自回归的。
2.在 LLM 中把温度（temperature）参数设为零（0）时，发生的就是贪心解码。
答案：零（0） 温度为零时模型每次都选择概率分数最高的词元，即贪心解码；温度概念将在第 6 章详细讨论。
3.lm_head_output 的形状为 [1, 5, 32064]，其中 32064 对应模型的词表大小。
答案：词表 语言建模头输出的每个向量包含词表中全部 32064 个词元的概率分数；批次维度为 1，序列长度为 5。
4.为了增强注意力能力，注意力机制被复制多份并行执行，这些并行的注意力执行过程被称为注意力头。
答案：头（attention head） 多个注意力头并行运行提高了模型对输入序列中复杂模式的建模能力，使其能同时关注不同的模式，各头输出最后被聚合为层的输出（见图 3-17）。
5.分组查询注意力（GQA）建立在多查询注意力（MQA）的基础之上。
答案：多查询（multi-query） MQA 在所有头之间共享键、值矩阵；GQA 进一步折中，允许分组共享键、值矩阵，在效率与质量之间取得平衡。
6.新版 Transformer 块中，归一化采用比 LayerNorm 更简单高效的RMSNorm。
答案：RMSNorm 参见论文"Root Mean Square Layer Normalization"；归一化还被移到注意力层和 FFN 层之前（预归一化），据称可减少所需训练时间。
7.现代模型常用 SwiGLU 等新激活函数变体，替代原始 Transformer 中的ReLU激活函数。
答案：ReLU 参见论文"GLU Variants Improve Transformer"；SwiGLU 等变体在当前 LLM 中更为常见。
8.RoPE 把位置信息混入查询矩阵和键矩阵，发生在将查询向量与键矩阵相乘进行相关性评分之前。
答案：相关性 旋转位置嵌入在注意力步骤中添加（而非前向传播开始时），在相关性评分之前把位置信息特意混合到查询和键中（见图 3-33）。

五、简答题 先在输入框中作答，再对照参考答案

1.简述 Transformer LLM 从接收提示词到持续生成文本的完整过程。
参考答案： 输入端：提示词先经分词器分解为词元并转换为词元 ID，模型取出对应的词元嵌入向量（加上位置信息），每个词元流入自己的计算流。
处理：计算依次经过堆叠的 Transformer 块（每块含自注意力层和前馈神经网络层），最后一个块的输出向量交给语言建模头。
输出端：语言建模头对词表中每个词元输出概率分数，解码策略（如按概率采样或贪心解码）从中选出下一个词元。
循环：生成的词元被追加到提示词末尾，更新后的提示词再次输入模型进行下一次前向传播，如此自回归地逐词元生成，直到结束。
2.为什么 KV 缓存能显著加速文本生成？请结合原理和书中的计时实验说明。
参考答案： 原理：生成第二个词元时，朴素做法是把新词元追加后对整个序列重新前向传播，之前的流会被重复计算。KV 缓存把之前词元在注意力机制中的键和值等特定向量缓存下来，这样生成新词元时只需计算最后一条活跃的计算流，避免重复计算。
实验：书中在 T4 GPU 上生成 100 个词元，启用缓存约 4.5 秒，禁用缓存（use_cache=False）约 21.8 秒，差异非常显著。
延伸：这也是 LLM API 在生成过程中流式输出词元的原因——让等待输出的用户更早看到内容。
3.注意力机制包含哪两个主要步骤？分别如何实现？
参考答案： 第一步·相关性评分：将当前位置的查询向量与键矩阵相乘，得到衡量前序每个词元相关性的分数，再通过 softmax 归一化使分数之和为 1。
第二步·信息组合：用每个词元对应的值向量乘以该词元的相关性分数，然后将结果向量相加，得到融合了上下文信息的输出向量。
意义：注意力把上下文中的相关信息整合进当前词元的表示，例如"The dog chased the squirrel because it"中判断 it 的指代对象（见图 3-14、图 3-20、图 3-21）。
4.比较多头注意力、多查询注意力和分组查询注意力的区别与权衡。
参考答案： 多头注意力（原始）：每个注意力头都有独立的一组查询、键、值矩阵，建模能力最强，但矩阵规模大、推理开销高（见图 3-26）。
多查询注意力（MQA）：所有头共享同一组键矩阵和值矩阵，只保留各自独特的查询矩阵；通过减小矩阵规模大幅提高推理可扩展性，但随着模型规模增长可能带来过大的性能损失。
分组查询注意力（GQA）：在 MQA 基础上允许使用多于一个但少于头数的键、值矩阵，分组共享；牺牲一些 MQA 的效率换取质量的大幅提升，被 Llama 2、Llama 3 等模型采用。
5.什么是旋转位置嵌入（RoPE）？相比静态绝对位置嵌入有什么优势？它在前向传播中的什么位置生效？
参考答案： 是什么：RoPE（rotary position embedding）是一种基于嵌入空间中旋转向量的位置编码方法。
优势：静态绝对位置嵌入（第一个词元标记为位置 1、第二个为位置 2，可为静态或可学习）在扩展到大规模和长上下文时面临挑战，如打包场景中文档 50 从位置 50 开始会误导模型；RoPE 能同时捕获绝对和相对词元位置信息，更适应打包等实践需求。
生效位置：与在前向传播开始时添加的静态绝对嵌入不同，RoPE 在注意力步骤中生效——把位置信息特意混合到查询矩阵和键矩阵中，发生在查询与键相乘进行相关性评分之前（见图 3-32、图 3-33）。
