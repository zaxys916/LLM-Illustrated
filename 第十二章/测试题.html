2.基座模型的主要局限是？
  • A参数量太小
  • B不会遵循指令，只会尝试预测下一个词
  • C训练数据太多
  • D推理速度太慢
答案：B 基座模型未被训练来遵循指令，它会补全问题而非回答问题（图12-5）。
3.全量微调与预训练的主要区别在于？
  • A全量微调使用较小但已标注的数据集
  • B全量微调不更新参数
  • C预训练使用 GPU
  • D全量微调需要更多显存
答案：A 全量微调在已标注的小数据集上更新全部参数；预训练在无标注大数据集上自监督学习（图12-6）。
4.参数高效微调（PEFT）的核心目标是？
  • A减少可训练参数，降低计算与存储成本
  • B增加模型层数
  • C替换所有权重
  • D删除基座模型
答案：A PEFT 通过只微调少量参数（如适配器或 LoRA），在保持性能的同时大幅降低训练成本。
5.适配器（Adapter）最早是为哪个模型提出的？
  • AGPT-3
  • BBERT
  • CTinyLlama
  • DT5
答案：B 适配器在论文"Parameter-Efficient Transfer Learning for NLP"中提出，仅微调 BERT 的 3.6% 参数即可接近全量微调性能。
6.LoRA 通过什么方式减少可训练参数？

  • C删除一半权重

7.QLoRA 中的"Q"代表什么？
  • AQuery

8.本章用于指令微调的开源小模型是？
  • APhi-3-mini

  • A学习率

10.QLoRA 训练完成后，合并权重时通常使用什么精度重新加载模型？

11.评估生成模型时，"困惑度"（Perplexity）衡量的是？

14.DPO（直接偏好优化）相比 PPO 的主要优势是？
  • A需要训练更多模型

16.创建高质量 LLM 通常包括哪三个步骤？
  • A预训练（语言建模）
  • B监督微调（SFT）
  • C偏好调优
  • D人工标注所有数据
答案：ABC 三步走：预训练产出基座模型 → 监督微调学会遵循指令 → 偏好调优对齐人类偏好（图12-3）。
17.关于 LoRA 的超参数，正确的有？
  • Ar 控制压缩矩阵的秩
  • Blora_alpha 经验上设为 r 的两倍
  • Ctarget_modules 决定哪些层被微调
  • Dr 越大压缩率越高
答案：ABC r 越大低秩矩阵越大，压缩率越低但表示能力越强；lora_alpha 平衡原始知识与新知识；target_modules 可选择特定投影层。
18.QLoRA 相比全量微调的优势包括？
  • A4 位量化显著降低显存占用
  • B只需训练少量 LoRA 参数，速度快
  • C显存需求从约 4GB 降至约 1GB（仅加载）
  • D必须使用更大的数据集
答案：ABC QLoRA 通过 4 位量化 + LoRA 低秩微调，在保持性能的同时大幅降低显存与计算成本。
19.评估生成模型的常用方法包括？
  • A词级指标（困惑度、ROUGE、BLEU）
  • B公共基准测试（MMLU、GSM8k、HumanEval）
  • C排行榜（Open LLM Leaderboard）
  • D人工评估与 LLM-as-a-judge
答案：ABCD 以上都是常见评估手段，但没有单一金标准，需根据应用场景组合使用。
20.偏好调优的三个阶段（使用奖励模型时）包括？
  • A收集偏好数据（被接受/被拒绝的生成内容）
  • B训练奖励模型
  • C用奖励模型作为评估器微调 LLM
  • D删除基座模型
答案：ABC 传统偏好调优（PPO）需要：收集偏好数据 → 训练奖励模型 → 用奖励模型微调 LLM（图12-30）。
21.关于 DPO 的说法，正确的有？
  • A不需要单独训练奖励模型
  • B使用参考模型与可训练模型的输出概率偏移
  • C比 PPO 训练更稳定、准确度更高
  • D必须使用 4 位量化
答案：ABC DPO 摒弃了强化学习流程，直接比较参考模型与可训练模型在被接受/被拒绝内容上的概率偏移，训练更稳定；量化是可选的显存优化手段。

  • √正确
  • ×错误

  • √正确
  • ×错误

  • √正确
  • ×错误
答案：√ 4 位量化显著压缩模型体积，加载显存约从 4GB 降至 1GB，但训练时显存需求会增加。

  • √正确
  • ×错误

27.奖励模型训练时，目标是让被接受的生成内容得分低于被拒绝的内容。

  • ×错误
答案：× DPO 摒弃了单独的奖励模型，直接用 LLM 的参考模型与可训练模型比较概率偏移。

五、简答题 点击「显示答案」查看参考答案

40.说明全量微调与 LoRA/QLoRA 的核心区别，并解释为什么 LoRA/QLoRA 更实用。
参考答案： 全量微调：更新模型全部参数，需要大量显存、算力和存储空间； LoRA：冻结原始权重，只训练两个低秩小矩阵，参数量从亿级降至万级； QLoRA：在 LoRA 基础上将基座模型 4 位量化，加载显存从约 4GB 降至约 1GB； 实用性：在消费级 GPU 上即可微调大模型，训练更快、存储更小，且性能接近全量微调。
41.描述偏好调优的两种主要方法（PPO 与 DPO）的工作流程及优缺点。
参考答案： PPO（基于奖励模型）：①收集偏好数据（被接受/被拒绝的生成内容）→ ②训练奖励模型 → ③用奖励模型通过强化学习微调 LLM。优点：经典有效；缺点：需训练两个模型，成本高、训练不稳定； DPO（直接偏好优化）：无需单独奖励模型，直接用参考模型与可训练模型的输出概率偏移来优化。优点：训练更稳定、成本更低、准确度更高；缺点：对参考模型质量有依赖。
42.为什么评估生成模型很困难？列举本章提到的评估方法并说明其局限。
参考答案： 困难原因：生成模型应用场景多样，单一指标无法覆盖；概率性导致输出不一致； 方法：①词级指标（困惑度、ROUGE）——无法衡量创造性/正确性；②基准测试（MMLU、GSM8k）——可能过拟合、覆盖不全；③排行榜——依赖公开基准；④LLM-as-a-judge——评判标准可能漂移；⑤人工评估（Chatbot Arena）——成本高、众包意见可能与实际场景脱节； 结论：没有金标准，需按应用场景组合评估，人工评估仍是最终裁判。
43.结合本章实验，说明 SFT 与 DPO 结合使用的意义及代价。
参考答案： 意义：SFT 让基座模型学会遵循指令、进行基础对话；DPO 在此基础上根据人类偏好进一步优化回答质量，使模型输出更符合期望； 实验：本章先用 QLoRA 对 TinyLlama 进行指令微调（SFT），再用 DPO 对指令模型进行偏好调优，最终模型能生成更符合人类偏好的回答； 代价：需要两轮独立的训练过程，每轮都需调整超参数，时间与计算成本翻倍；ORPO 等新方法尝试将两者合并以降低成本。
44.如果你要在自己的项目中微调一个 7B 模型，你会选择全量微调、LoRA 还是 QLoRA？请结合本章内容说明理由。
参考答案： 推荐 QLoRA：7B 模型全量微调需要数十 GB 显存，消费级 GPU 无法承受；QLoRA 通过 4 位量化将加载显存降至约 1GB，配合 LoRA 低秩微调，可在单张消费级显卡（如 RTX 4070 Ti 12GB）上完成训练； 性能：论文证明 LoRA/QLoRA 在多数任务上性能接近全量微调； 灵活性：训练后的 LoRA 权重可独立保存与合并，便于管理多个任务适配器； 注意事项：需合理设置 r（通常 4-64）、lora_alpha（约 2r）、target_modules，并使用 16 位精度合并权重以获得最佳推理质量。
