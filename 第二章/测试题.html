一、单选题 每题只有一个正确答案

1.语言模型处理文本时会先将其分成小块，这些小块称为？
  • A词元（token）
  • B句子（sentence）
  • C段落（paragraph）
  • D字节（byte）
答案：A 语言模型处理文本时会将其分成小块，称为词元；为理解自然语言，模型再把词元转换为数值表示，即嵌入向量（见图 2-1）。
2.提示词经过分词器处理后，模型实际接收到的 input_ids 是什么？
  • A原始文本字符串
  • B一系列整数（词元 ID）
  • C浮点数矩阵
  • D布尔值列表
答案：B 模型并不直接处理提示词文本，分词器在 input_ids 中返回一系列整数，每个整数都是特定词元（字符、词或词的一部分）的唯一 ID，即分词器内部词元表的索引（见图 2-4）。
3.Phi-3 示例中第一个词元是 ID 1（<s>），它的作用是？
  • A表示文本开始
  • B表示文本结束
  • C表示未知词
  • D用于填充空位
答案：A 第一个词元是 ID 1（<s>），这是一个表示文本开始的特殊词元；而结束词元则用来向系统表明模型已完成生成。
4.若想把词元 ID 转换回人类可读的文本，应使用分词器的哪个方法？
  • Aencode
  • Bdecode
  • Csplit
  • Dmap
答案：B 使用分词器的 decode 方法可以将 ID 转换回文本，可传入单个词元 ID，也可传入它们的列表；分词器在输入端和输出端都靠它完成转换。
5.下列哪种分词方法被广泛用于 GPT 模型？
  • A字节对编码（BPE）
  • BWordPiece
  • CSentencePiece
  • D词级分词
答案：A 字节对编码（BPE）被广泛用于 GPT 模型；WordPiece 用于 BERT 模型。它们都旨在找到一组尽可能高效的词元来表示文本数据集，但实现方式不同。
6.BERT 模型采用的分词方法是？
  • ABPE
  • BWordPiece
  • C字符级分词
  • D字节级分词
答案：B BERT 使用 WordPiece 方法（参见论文「Japanese and Korean Voice Search」），子词用 ## 前缀表示与前面的词元相连。
7.词级分词（如早期 word2vec）面临的一个主要挑战是？
  • A无法处理分词器训练完成之后才出现的新词
  • B词表过小无法表示常用词
  • C不能编码英语文本
  • D无法表示标点符号
答案：A 词级分词器可能无法处理训练完成之后才出现在数据集中的新词（OOV），还会让词表中存在大量仅有细微差别的词元（如 apology、apologize、apologetic、apologist）。
8.与子词级分词相比，字符级分词的主要缺点是？
  • A无法处理新词
  • B词表规模太大
  • C不能表示字母
  • D序列过长，建模更困难
答案：D 字符级只依赖最原始的字母，虽容易处理新词，但模型需要建模拼写出 p-l-a-y 的信息以及序列其余部分，建模更困难；子词级中一个词元即可表示 play。
9.在上下文长度为 1024 的模型中，使用子词级分词约可容纳字符级分词多少倍的文本？
  • A相同
  • B约两倍
  • C约三倍
  • D约十倍
答案：C 子词级词元平均每个包含约三个字符，因此在有限的上下文长度内可容纳字符级分词约三倍的文本。
10.BERT 大小写不敏感基座分词器的词表大小是？
  • A30522
  • B32100
  • C50257
  • D100000
答案：A BERT 基座分词器（2018）词表大小为 30522，特殊词元包括 [UNK]、[SEP]、[PAD]、[CLS]、[MASK]。
11.GPT-2 分词器的词表大小为？
  • A30522
  • B32100
  • C50257
  • D49152
答案：C GPT-2（2019）使用 BPE 方法，词表大小 50257，特殊词元为 <|endoftext|>。
12.GPT-4 分词器对连续空白字符的处理是？
  • A全部拆成单个空格词元
  • B将四个空白字符表示为单个词元，甚至为最长 83 个空白序列设有特定词元
  • C直接删除所有空白
  • D用 [UNK] 表示空白
答案：B GPT-4 把四个空白字符表示为单个词元，甚至为各种长度（最多 83 个）的空白字符序列都设有特定词元，这源于模型对代码的关注——单词元表示缩进更利于处理 Python 代码。
13.StarCoder2 分词器对数字的处理方式是？
  • A每个数字都分配一个词元（600 → 6、0、0）
  • B所有数字共用一个词元
  • C先把数字转换成英文单词
  • D无法表示数字
答案：A StarCoder2 为每个数字都分配词元（600 变成 6 0 0），这种设计假设能更好地表示数字和数学概念；相比之下 GPT-2 中 870 是一个词元、871 却拆成 8 和 71，可能让模型混淆数字。
14.DeBERTaV3 处理 “Hello world” 时，每个词元的嵌入向量包含多少个值？
  • A128
  • B384
  • C512
  • D768
答案：B DeBERTaV3（deberta-v3-xsmall）输出形状为 (1, 4, 384)：可理解为 4 个词元（[ CLS]、Hello、world、[SEP]），每个词元嵌入到含 384 个值的向量中，第一维是批次维度。
15.使用 all-mpnet-base-v2 模型，一个句子被编码成的文本嵌入向量维度是？
  • A32
  • B384
  • C768
  • D1024
答案：C all-mpnet-base-v2 经 sentence-transformers 把句子编码成维度 768 的向量，用单个向量捕捉整句含义；嵌入维度取决于底层嵌入模型。

1.决定分词器如何分解输入文本的主要因素有哪些？
  • A模型创建者选择的分词方法（如 BPE、WordPiece）
  • B分词器设计选择，如词表大小和特殊词元
  • C训练分词器所用的特定数据集
  • D运行设备的显示器尺寸
答案：ABC 决定分词器行为的三大因素：分词方法、词表大小与特殊词元等设计选择、以及训练分词器的数据集；即使方法和参数相同，在英语、代码或多语言数据上训练的分词器也会不同。D 与之无关。
2.下列哪些属于 BERT 大小写不敏感分词器的特殊词元？
  • A[UNK]（未知词元）
  • B[SEP]（分隔符词元）
  • C[PAD]（填充词元）
  • D[MASK]（掩码词元）
答案：ABCD 这四个都属于 BERT 特殊词元；此外还有用于分类的 [CLS] 词元。[SEP] 用于需要两段文本的任务（此时模型称交叉编码器），[MASK] 在训练中用于隐藏词元。
3.关于 BERT 大小写不敏感分词器，下列说法正确的有？
  • A换行符消失了，模型无法识别换行体现的信息

答案：ABCD 四项均为该分词器的特点：换行消失、全部小写、capitalization 拆成 capital ##ization（## 表示与前面相连）、emoji 和中文变为未知词元 [UNK]。
4.word2vec 算法背后的两个主要思想是？

答案：AB word2vec 的两个主要概念：skip-gram（选择相邻词的方法）和负采样（通过随机采样添加负例），见图 2-14。C、D 是通用训练技巧，并非其核心思想。
5.本章训练歌曲嵌入模型时，Word2Vec 使用了下列哪些参数设置？

6.语言模型生成的与上下文相关的词嵌入可用于下列哪些应用？

三、判断题 判断下列说法是否正确

1.语言模型并不是一次性生成所有输出，而是一次生成一个词元。
  • √正确
  • ×错误
答案：√ 词元不仅是模型的输出单位，也是模型查看输入的方式；提示词首先被分解成词元，输出也逐词元生成。
2.空格字符需要用单独的词元来表示。
  • √正确
  • ×错误
答案：× 空格字符不用单独的词元表示；代表词的一部分的词元（如 izing、ic）开头有特殊隐藏字符表示与前面词元相连，无此字符的词元前面则被视为有一个空格。标点符号才是独立的词元。
3.BERT 大小写不敏感分词器会让换行符消失，而 GPT-2 分词器保留换行符。
  • √正确
  • ×错误
答案：√ BERT uncased 中换行符消失，使其无法识别换行体现的信息（如每行一轮的聊天记录）；GPT-2 则保留换行符。
4.子词级分词无法表示训练时从未见过的新词。
  • √正确
  • ×错误
答案：× 子词级分词的优势之一正是能够表示新词：可将新词分解成较小的、通常已在词表中的子词（如把陌生词拆成已知词根与后缀）。
5.FLAN-T5 使用 SentencePiece 方法，该方法中没有换行符或空白字符词元。
  • √正确
  • ×错误
答案：√ FLAN-T5（2022）用 SentencePiece（支持 BPE 和一元语言模型），该方法没有换行符或空白字符词元，使模型处理代码具有挑战性；表情符号和中文也都被替换为 <unk>。
6.因为 GPT-2、RoBERTa 分词器的词表中含有字节词元，所以它们属于无分词的字节级分词器。
  • √正确
  • ×错误
答案：× 它们只是在遇到无法用其他方式表示的字符时，把字节作为最终备选方案（如 emoji），并非用字节表示一切，因此不是免分词的字节级分词器。字节级代表是 CANINE、ByT5。
7.在本章考察的所有分词器中，Galactica 是唯一一个将两个制表符组成的字符串分配为单个词元的。
  • √正确
  • ×错误
答案：√ Galactica 对空白字符和制表符都把不同长度序列编码为单个词元，是本章中唯一将两个制表符（\t\t）分配为单个词元的分词器。
8.语言模型中词元的嵌入向量在训练开始之前就已被赋予固定含义。
  • √正确
  • ×错误
答案：× 这些向量在训练开始前像其他权重一样被随机初始化，并无含义；训练过程才为它们分配值，使其能够执行有意义的行为。
9.生成文本嵌入只能通过对所有词元嵌入取平均值，即便是高质量模型也不采用其他方式。
  • √正确
  • ×错误
答案：× 对词元嵌入取平均值确实是最常见的方法之一，但高质量的文本嵌入模型（如 all-mpnet-base-v2）往往是专门为文本嵌入任务训练的，并非只能取平均。
10.在歌曲推荐示例中，把每首歌曲当作一个词元、每个播放列表当作一个句子来训练嵌入。
  • √正确
  • ×错误
答案：√ 把每首歌当作词或词元、每个播放列表当作句子，用 word2vec 训练出的嵌入就能推荐经常出现在同一播放列表中的歌曲。

五、简答题 先在输入框中作答，再对照参考答案

1.简述分词器如何处理 LLM 的输入，input_ids 是什么？它与 decode 方法有何关系？
参考答案： 处理流程：模型并不直接处理提示词文本。提示词先由分词器分解成片段（词元），分词器在变量 input_ids 中返回模型所需的信息。
input_ids：一系列整数（词元 ID），每个整数都是特定词元（字符、词或词的一部分）的唯一 ID，是分词器内部词元表（包含它能识别的所有词元）的索引，这才是语言模型的实际输入。
decode：用分词器的 decode 方法可把词元 ID 转换回人类可读文本，可传入单个 ID 或 ID 列表；模型输出端同样靠它把生成的 ID 转成文本。
细节：第一个词元常是表示文本开始的特殊词元（如 Phi-3 的 ID 1 <s>），词元可以是完整词、词的部分，标点是独立词元，空格不单独表示。
2.对比词级、子词级、字符级三种分词方式，分别说明其优缺点。
参考答案： 词级：在早期 word2vec 等模型中常见，因实用性在推荐系统等 NLP 之外场景沿用。缺点是无法处理训练后出现的新词（OOV），且词表中存在大量细微差别的词元（apology、apologize、apologetic、apologist）。
子词级：包含词和词的一部分，是最常用的方案。优点是词表更具表达能力（共用 apolog 词根与 -y、-ize、-etic、-ist 等后缀），且能把未见过的新词拆成已知子词来表示；在有限上下文内比字符级容纳更多文本（约三倍）。
字符级：只依赖最原始的字母，能成功处理任意新词，分词更容易；但序列显著变长，模型需建模 p-l-a-y 等拼写信息，建模更困难，也更占上下文长度。
3.以 BERT 大小写不敏感版和 GPT-2 为例，比较它们在换行符、大小写、表情符号与中文字符处理上的差异。
参考答案： 换行符：BERT uncased 中换行符消失，模型无法识别换行体现的信息；GPT-2 保留换行符。
大小写：BERT uncased 先把所有大写字母转成小写（capitalization → capital、##ization）；GPT-2 保留大小写，CAPITALIZATION 被表示为四个词元。
表情符号与中文：BERT uncased 把表情符号和中文字符替换为 [UNK]（未知词元）；GPT-2 则把它们分解为多个字节词元——例如 🎶 被拆成 ID 8582、236、113，decode([8582,236,113]) 能重构出 🎶。
补充：GPT-2 用词表中的字节词元作为无法表示字符的最终备选，但它并非用字节表示一切，故不是字节级（免分词）分词器。
4.简述 word2vec 如何利用滑动窗口生成训练样本，并说明为什么必须引入负例（负采样）。
参考答案： 滑动窗口：word2vec 从文本生成样本。设窗口大小为 2，即考虑中心词两侧各两个相邻词。窗口在每个位置以中心词为第一个输入、各相邻词为第二个输入生成样本（skip-gram），期望模型对相邻词对输出 1。
训练目标：本质是一个分类任务——神经网络接收两个词，若它们倾向于出现在相同上下文中则输出 1，否则输出 0。
为何需要负例：若只有目标为 1 的正例，模型会投机取巧，靠一直输出 1 获得完美表现。因此要用通常不相邻的词作为负例（目标 0）。
负采样：选择负例不必很严谨，从数据集随机取一些词标注为非相邻词即可，这受到噪声对比估计（NCE）启发。据此不断调整每个词元的嵌入向量，训练结束后所有词元得到更好的词嵌入。
5.如何用 word2vec 构建歌曲推荐系统？说明「歌曲=词元、播放列表=句子」的思路、数据来源与关键参数。
参考答案： 核心思路：把每首歌曲当作一个词或词元、把每个播放列表当作一个句子，用 word2vec 在人工创建的音乐播放列表上训练歌曲嵌入；所得嵌入可推荐经常出现在同一播放列表中的歌曲。
数据集：Playlist 数据集由康奈尔大学的 Shuo Chen 收集，包含来自美国数百个广播电台的播放列表；训练时删除只有一首歌的播放列表，并加载歌曲元数据（标题、艺术家）。
关键参数：Word2Vec(playlists, vector_size=32, window=20, negative=50, min_count=1, workers=4)，训练一两分钟即为每首歌曲算出嵌入。
推荐方式：用 model.wv.most_similar(positive=歌曲ID, topn=5) 找嵌入最近邻。实测 Michael Jackson 的 Billie Jean（ID 3822）会推荐 Madonna、Prince 及他自己的其他歌曲；2Pac 的 California Love（ID 842）也能给出合理的说唱近邻。
