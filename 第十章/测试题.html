  • A嵌入（embedding）
  • B分词（tokenization）
  • C池化（pooling）
  • D掩码（masking）
答案：A 嵌入即对输入进行嵌入处理，以输出可用的向量（如图 10-1 所示），对输入进行嵌入通常由 LLM 执行，我们称之为嵌入模型。
2.构建情感分类器时，我们可以微调嵌入模型，使文档在 n 维空间中的距离基于什么？
  • A语义特性
  • B情感倾向
  • C词频统计
  • D句子长度
答案：B 如图 10-3 所示，嵌入模型可以针对多种目的进行训练；构建情感分类器时更关注文本的情感倾向而非语义相似性，使负面评价彼此接近、并与正面评价明显不同。
3.训练、微调和引导嵌入模型的方法很多，其中最强大且应用最广泛的技术是？
  • A掩码语言建模
  • B对比学习
  • C梯度提升
  • D规则匹配
答案：B 对比学习的目标是训练嵌入模型，使相似文档在向量空间中距离更近，而不相似文档相距更远，它与第 2 章中的 word2vec 方法非常相似。
4.作为 NLP 领域最早且最流行的对比学习例子之一，word2vec 是如何构建训练对的？
  • A靠近目标词的词构建成正例对，随机采样的词构建成负例对
  • B所有词两两构建正例对
  • C词频高的词构建负例对
  • D人工标注相似词对
答案：A word2vec 通过将目标词的相邻词与非相邻词进行对比来训练模型，这是自然语言处理领域利用神经网络进行对比学习的首批重大突破之一。
5.在 sentence-transformers 诞生之前，句子嵌入通常使用什么架构结合 BERT 模型来实现？
  • A双编码器（bi-encoder）
  • B交叉编码器（cross-encoder）
  • C自编码器（auto-encoder）
  • D生成对抗网络（GAN）
答案：B 交叉编码器允许两个句子同时通过 Transformer 网络处理，通过在原始架构上添加分类头来输出两个句子的相似度分数。
6.用交叉编码器在包含 10000 个句子的集合中找相似度最高的配对，需要进行多少次推理计算？
  • A10000
  • B100000
  • C49995000
  • D100000000
答案：C 需要进行 n*(n-1)/2 = 49995000 次推理计算，因此会产生巨大的开销；此外交叉编码器通常不会生成嵌入向量，而是输出相似度分数。
7.通过计算 BERT 输出层的平均值或使用 [CLS] 词元来生成嵌入向量，其效果已被证明比什么还要差？
  • A随机初始化向量
  • B独热编码
  • C简单地计算词向量的平均值（如 GloVe）
  • D词袋模型
答案：C 正是这种不足，促使 sentence-transformers 的作者找到一种能快速创建可进行语义比较的嵌入向量的优雅方案。
8.在 sentence-transformers 中，分类头被移除后，用什么来生成固定维度的嵌入向量？
  • A在最终输出层上使用平均池化
  • B更大的分类头
  • C随机投影矩阵
  • D额外的 CNN 层
答案：A 池化层通过对词嵌入取平均值，生成一个固定维度的输出向量，从而确保嵌入向量的大小固定。
9.sentence-transformers 的训练使用孪生（siamese）架构，关于这种架构下列说法正确的是？
  • A两个 BERT 模型各自独立训练，互不相关
  • B两个完全相同的 BERT 模型共享权重和神经网络架构，因此可用单个模型依次输入句子
  • C只需要一个分类头连接两个不同的模型
  • D两个模型一个处理文本一个处理图像
答案：B 如图 10-7 所示，孪生网络（也称双编码器）中两个模型接收句子作为输入，通过对词元嵌入进行池化来生成嵌入向量，然后根据句子嵌入的相似度进行优化。
10.原始 sentence-transformers 的训练过程中，每个句子的嵌入向量与它们之间的差向量拼接后，用什么进行优化？
  • Asigmoid 回归器
  • Bsoftmax 分类器
  • C决策树
  • D聚类算法
答案：B 句子对的优化通过损失函数完成，损失函数的设计会对模型性能产生重大影响；最早使用的就是 softmax 损失函数。
11.本章从头训练嵌入模型时，选用哪个预训练 Transformer 模型作为嵌入单词的入门模型？
  • Abert-base-uncased（不区分大小写版）

  • DRoBERTa-large
答案：A 通常我们会选择现有的 sentence-transformers 模型进行微调，但本章示例从头训练，使用 BERT 基座模型（不区分大小写版）；值得一提的是，用 microsoft/mpnet-base 作词嵌入模型通常也能得到不错的结果。
12.在 softmax 损失函数中，除了模型和嵌入维度外，还需要显式设置什么？

13.使用 softmax 损失函数从头训练模型后，评估得到的 pearson_cosine 基准值是？
  • A0.539
  • B0.72
  • C0.80
  • D0.85
答案：A pearson_cosine 是中心化向量之间的余弦相似度，值介于 0 和 1 之间，越大表示相似度越高；0.539 在本章中作为基准值（余弦相似度损失 0.72、MNR 损失 0.80、监督微调 0.85）。

15.多负例排序损失函数（MNR）也常被称为？
  • AInfoNCE 或 NTXentLoss
  • BMarginMSE
  • CTripletLoss
  • DSoftmaxLoss
答案：A MNR 使用正例句子对或包含一对正例句子和一个不相关句子的三元组；其中不相关的句子被称为负例，负例对通过混合不同正例对的元素生成，称为批内负例。

三、判断题 判断下列说法是否正确

1.虽然二维可视化有助于说明嵌入向量的接近度和相似性，但这些嵌入向量通常存在于高维空间中。
  • √正确
  • ×错误
答案：√ 图 10-2 只是一个简化的例子，实际嵌入向量通常存在于 n 维（高维）空间中。
2.对比学习只需向模型输入相似的文档对，无须输入不相似的文档对。
  • √正确
  • ×错误
答案：× 对比学习的基本理念是向模型输入相似的和不相似的文档对作为示例，模型通过对比学习使这些文档相似或不相似的特征。
3.交叉编码器通常会生成嵌入向量，便于快速检索相似句子。
  • √正确
  • ×错误
答案：× 如图 10-6 所示，交叉编码器通常不会生成嵌入向量，而是输出输入句子之间的相似度分数。
4.虽然双编码器的运算速度相当快并能创建精准的句子表示，但交叉编码器通常比双编码器具有更好的性能。
  • √正确
  • ×错误
答案：√ 书中明确指出，交叉编码器通常比双编码器性能更好，并且无须生成嵌入向量；这也是增强型 SBERT 用交叉编码器来标注白银数据集的原因之一。
5.训练 sentence-transformers 模型时，通常建议冻结部分层以获得更好的性能。
  • √正确
  • ×错误
答案：× 默认所有层都是可训练的；虽然可以冻结某些层，但通常不建议，因为在所有层都解冻的情况下，模型性能往往更好。
6.数据集越小，训练或微调嵌入模型就越不稳定；在保证数据质量的前提下，最好使用更大的数据集。
  • √正确
  • ×错误
答案：√ 本章为缩短训练时间仅使用 MNLI 中的 50000 个标注句子对创建最小示例，但书中提醒数据集越小训练越不稳定。
7.要将余弦相似度损失函数用于 NLI 数据集，本章将蕴含的相似度分数设为 1，中性和矛盾的相似度分数设为 0。
  • √正确
  • ×错误
答案：√ 蕴含表示句子之间相似度高，故设为 1；中性和矛盾都表示相似度不高，故设为 0（对应代码中的 mapping = {2: 0, 1: 0, 0: 1}）。
8.使用 MNR 损失函数时，较大的批量大小通常表现更好，因为模型需要从更大的潜在句子对集合中找到最匹配的句子。
  • √正确
  • ×错误
答案：√ 更大的批量会使任务更具挑战性，因为批内负例更多，模型需要从更大的潜在句子对集合中找到最匹配的句子。
9.难负例是指与问题完全不相关的句子，因此很容易与正确答案区分。
  • √正确
  • ×错误
答案：× 与问题完全不相关的是简单负例；难负例与问题相关但不是正确答案，例如用「乌得勒支人口超百万」回答「阿姆斯特丹有多少人口」。
10.TSDAE 训练完成后，我们需要同时使用编码器和解码器来从文本生成嵌入向量。
  • √正确
  • ×错误
答案：× 训练完成后只需使用编码器生成嵌入向量，因为解码器仅用于判断嵌入向量是否能准确地重建原始句子。

五、简答题 先在输入框中作答，再对照参考答案

1.什么是对比学习？请结合「抢银行」的趣闻说明什么是对比解释。
参考答案： 对比学习：训练和微调文本嵌入模型的一种主要技术，目标是训练嵌入模型，使相似文档在向量空间中距离更近，而不相似文档相距更远。其基本理念是向模型输入相似的和不相似的文档对作为示例，让模型学习使文档相似或不相似的特征。
对比解释：通过与其他选择进行对比来理解特定情况，即通过「为什么是 P 而不是 Q」理解「为什么是 P」。
趣闻：记者问劫匪「你为什么要抢银行」，劫匪答「因为银行里有钱」。答案在事实上正确，但记者的本意是问为什么抢劫而非为什么去银行——若把问题建模为「为什么要抢银行（P）而不是遵守法律（Q）」，就能获得更准确的解释。
启示：当把问题构建为对比形式时，我们能获得更多信息；例如问模型「为什么这是一只狗而不是一只猫」，模型便开始学习定义概念的特征以及哪些特征与之无关。
2.对比交叉编码器与双编码器（SBERT）的架构差异，并说明各自的优劣。
参考答案： 交叉编码器：两个句子连接在一起、用 <SEP> 词元分隔后作为一个整体同时通过 Transformer 处理，分类头输出相似度分数；通常不生成嵌入向量。
交叉编码器的缺点：在 10000 个句子的集合中找最相似配对需要 n*(n-1)/2=49995000 次推理，计算开销巨大。
双编码器（SBERT）：采用孪生架构，两个完全相同的 BERT 模型共享权重；移除分类头，在最终输出层用平均池化生成固定维度的句子嵌入，再根据句子嵌入的相似度优化；由于权重共享，可用单个模型依次输入句子。
优劣对比：双编码器运算速度快、能创建精准的句子表示并可预先计算嵌入用于检索；交叉编码器通常性能更好且无须生成嵌入向量，但推理昂贵。两者都基于对比学习。
3.简述余弦相似度损失函数与多负例排序损失函数（MNR）的原理，并对比本章实验结果。
参考答案： 余弦相似度损失：不严格区分句子对是正例还是负例，而是假设句子对在一定程度上相似或不相似（分数介于 0 和 1）；先计算两段文本嵌入向量的余弦相似度，再与标注的相似度分数比较，目标是最小化相似句子间的余弦距离、最大化不相似句子间的余弦距离。用于 NLI 时将蕴含映射为 1、中性和矛盾映射为 0。
MNR 损失（InfoNCE/NTXentLoss）：使用正例对或三元组（锚句、正例、负例），负例通过混合不同正例对的元素生成（批内负例）；计算嵌入向量的余弦相似度后，把「这些文本对是负例对还是正例对」视为分类任务，用交叉熵损失优化。较大的批量通常表现更好。
实验结果：softmax 损失 pearson_cosine 为 0.539（基准），余弦相似度损失提升到 0.72，MNR 损失进一步提升到 0.80，显示了损失函数对模型性能的影响。
4.简述增强型 SBERT 的四个步骤，并解释黄金数据集与白银数据集的区别。
参考答案： 动机：训练或微调嵌入模型通常需要大量训练数据（许多模型用超过十亿个句子对训练），但实际常只有几千个标注数据点，增强型 SBERT 可在少量标注数据下微调嵌入模型。
四个步骤：步骤 1，使用小型标注数据集（黄金数据集）微调交叉编码器（BERT）；步骤 2，创建新的句子对；步骤 3，使用微调后的交叉编码器标注新的句子对（白银数据集）；步骤 4，在扩展数据集（黄金+白银）上训练双编码器（SBERT）。
黄金数据集：规模较小但完全标注，包含真实标注（本章用 10000 个文档）。
白银数据集：也是完全标注的，但不一定是真实标注，由交叉编码器的预测生成（本章用剩余 40000 个句子对）。
效果：余弦相似度损失原始版本用完整数据集得 0.72，而仅用其中 20% 的数据经增强后获得 0.71；还可以通过仅在黄金数据集上训练来测试白银数据集的质量。
5.简述 TSDAE 的无监督训练原理，并说明如何用它进行领域适配。
参考答案： 原理：TSDAE 假设完全没有标注数据。通过删除输入句子中一定比例的词来添加噪声，「受损」句子被输入带池化层的编码器映射为句子嵌入，解码器再基于该嵌入尝试重建不含噪声的原始句子——句子嵌入越准确，重建的句子就越准确。它与掩码语言建模相似，但不是重建被掩码的词，而是重建整个句子。
实现要点：使用 DenoisingAutoEncoderLoss（去噪自编码器损失函数）；采用 [CLS] 词元作为池化策略（平均池化会丢失位置信息）；编码器嵌入层与解码器输出层绑定共享权重；因内存占用增加需减小批量大小。训练完成后仅用编码器生成嵌入。本章用无标注数据训练获得了 0.70 的分数。
领域适配（自适应预训练）：先用无监督技术（如 TSDAE 或掩码语言建模）在特定领域的语料库上预训练，再使用域内或域外的训练数据对模型进行监督微调（如常规监督训练或增强型 SBERT），使嵌入模型从一个领域泛化到另一个领域。
